# 📊 Data — Exercícios e Estudos em Ciência de Dados

Repositório dedicado a exercícios práticos, simulações estatísticas, análises exploratórias e projetos de aprendizado de máquina desenvolvidos durante a trilha trainee do **Núcleo de Dados da Síntese Jr.** e estudos complementares.

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Linguagem:** Python 3
* **Manipulação e Análise de Dados:** Pandas, NumPy
* **Visualização de Dados:** Seaborn, Matplotlib
* **Machine Learning:** Scikit-Learn
* **Ambientes:** VS Code, Google Colab / Jupyter Notebook
