# 📊 Data — Exercícios e Estudos em Ciência de Dados

Repositório dedicado a exercícios práticos, simulações estatísticas, análises exploratórias e projetos de aprendizado de máquina desenvolvidos ao longo da minha graduação em Sistemas de Informação, estudos independentes e trilhas de capacitação na área de Dados.

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Linguagem:** Python 3
* **Manipulação e Análise de Dados:** Pandas, NumPy
* **Visualização de Dados:** Seaborn, Matplotlib
* **Machine Learning:** Scikit-Learn
* **Ambientes:** VS Code, Google Colab / Jupyter Notebook
