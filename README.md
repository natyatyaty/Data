## 🚀 Como Executar os Arquivos

1. Clone o repositório para a sua máquina local:
   ```bash
   git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
   ```
2. Acesse a pasta `Data` e o diretório do exercício desejado:
   ```bash
   cd seu-repositorio/Data/nome-do-exercicio
   ```
3. Para scripts Python (`.py`), execute via terminal:
   ```bash
   python nome_do_arquivo.py
   ```
4. Para notebooks (`.ipynb`), abra o arquivo no **VS Code**, **Jupyter Notebook** ou importe diretamente no **Google Colab**.
